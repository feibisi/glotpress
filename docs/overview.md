### 1.1 概述

GlotPress 被设计为尽可能易于使用，但是翻译并不是一项简单的任务，一些细节对于第一次使用的用户来说可能并不明显。
本手册将为初次使用的用户和有经验的用户填写详细信息。
该手册是为 GlotPress 作为 WordPress 插件而设计的，但是许多通用概念在插件和独立安装中都适用。
该手册包含 14 个部分：

1. [概述](/document/glotpress/overview/)：此页面
2. [安装](/document/glotpress/installation/)：安装GlotPress的基本步骤
3. [配置](/document/glotpress/configuration/): 使用 GlotPress 前需要检查的一些配置项
4. [概述](/document/glotpress/general-overview/): GlotPress 概述
5. [用户](/document/glotpress/users/)：GlotPress 如何与 WordPress 用户合作
6. [管理员用户](/document/glotpress/admin-users/)：如何创建管理员用户
7. [访问 GlotPress](/document/glotpress/accessing-glotpress/) : 如何在您的 WordPress 网站上访问 GlotPress
8. [创建新项目](/document/glotpress/creating-a-new-project/): 如何在 GlotPress 中创建新项目
9. [项目操作和翻译](/document/glotpress/project-actions/)：现在 GlotPress 中拥有了一个新的项目，您可以做什么？
10. [译文集](/document/glotpress/translation-sets/)：如何管理项目中的译文集
11. [编辑字符串](/document/glotpress/editing-a-string/)：如何实际翻译字符串
12. [语言环境](/document/glotpress/locales/)：按语言环境查看项目
13. [词汇表](/document/glotpress/glossaries/)：使用词汇表
14. [您的个人资料](/document/glotpress/your-profile/)：编辑您的 GlotPress 个人资料
